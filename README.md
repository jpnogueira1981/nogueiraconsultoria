# ⚖️ Nogueira Consultoria Jurídica - Landing Page

Landing page institucional e de alta conversão desenvolvida para a **Nogueira Consultoria Jurídica**, escritório especializado em Direito Bancário, defesa em ações de **Busca e Apreensão de Veículos** e proteção patrimonial.

O design foi rigorosamente inspirado na identidade visual do cartão de visita do escritório, utilizando uma paleta sofisticada em **Azul Marinho Real** e **Dourado Ouro**, além do emblema vetorial exclusivo (balança e monograma).

---

## 🚀 Principais Funcionalidades

- **Design Exclusivo & Sofisticado:** Paleta de cores baseada em tons de azul profundo e detalhes em gradiente dourado.
- **Emblema Vetorial Personalizado:** Logotipo do escudo com as balanças da justiça integrado via SVG diretamente no cabeçalho, hero e rodapé.
- **Foco em Conversão (CTA Direta para o WhatsApp):** Vários pontos de contato estratégico com mensagens automáticas pré-configuradas para atendimento de urgência.
- **Seção de Transparência e Credibilidade:** Exibição clara e ostensiva do **CNPJ (55.294.742/0001-69)** e do registro na **OAB/PE (41.194)** para mitigar qualquer receio de golpe por parte dos leads.
- **Seções Informativas Completas:**
  - *Áreas de Atuação* (Busca e Apreensão, Revisão de Contratos, Renegociação).
  - *Fluxo de Atendimento* (Passo a passo transparente de como a defesa é protocolada).
  - *FAQ Interativo* (Accordion dinâmico com JavaScript puro respondendo às principais dúvidas dos clientes).
- **Totalmente Responsivo:** Otimizado para dispositivos móveis (smartphones), onde a grande maioria dos clientes acessará via links de campanhas de WhatsApp.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído seguindo o padrão de **Single-File Application (Single HTML)**, garantindo facilidade de deploy e performance máxima:

- **HTML5** (Semântico e estruturado)
- **Tailwind CSS** (Via CDN com extensão de paleta de cores personalizada e utilitários modernos)
- **Font Awesome 6** (Ícones profissionais)
- **Google Fonts** (Cinzel e Montserrat para tipografia jurídica elegante)
- **JavaScript Vanilla** (Para controle do menu mobile e comportamento do acordeão FAQ)

## ⚙️ Como Executar Localmente

Como o projeto é estático, você não precisa de instalações complexas de Node.js ou pacotes externos.

1. Faça o clone deste repositório:
   ```bash
   git clone https://github.com/seu-usuario/nogueira-consultoria-juridica.git
   ```
2. Abra a pasta do projeto no seu editor de código favorito (como o **VS Code**).
3. Abra o arquivo `index.html` diretamente no seu navegador de preferência ou utilize a extensão **Live Server** do VS Code.

## 🌐 Publicação e Hospedagem (Deploy)

A página pode ser publicada de forma gratuita e imediata em plataformas de hospedagem estática, tais como:
